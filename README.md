# Tos.lt — redesign concept (LT / EN / RU)

Неофициальный дизайн-концепт сайта [tos.lt](https://www.tos.lt/) (UAB «Technologies Of Security»):
первая версия с современной вёрсткой и переключателем языка **LT · EN · RU**.

**Это не официальный сайт компании** и не её публикация — только демонстрация возможных улучшений.
Страница закрыта от индексации поисковиками (`noindex`).

## Что внутри
- Один статический файл `index.html` + папка `images/` — без сборки, без зависимостей, без трекеров.
- Тексты на литовском взяты с tos.lt (исправлены только опечатки), EN и RU — перевод тех же сведений.
- Сайт всегда открывается на литовском; переключатель LT · EN · RU меняет язык, а ссылка вида `?lang=en` открывает сразу нужный.
- На втором аттестате закрыт личный код физического лица.

## Запуск
Открыть `index.html` в браузере. Или любой статический сервер, например:

```bash
python -m http.server 8080
```

Материалы компании (название, логотип, фотографии, аттестаты) принадлежат их владельцам.
